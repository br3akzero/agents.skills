# Xcode Lint

Run SwiftLint to check for code style violations in the current project.

## Command

```bash
swiftlint
```

## Instructions

1. Run the swiftlint command above from the project root
2. Report any warnings or errors found
3. If no issues, confirm the code passes linting
4. Group issues by severity (errors vs warnings) if there are many
